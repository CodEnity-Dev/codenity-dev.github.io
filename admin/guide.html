🚀 Getting Started

Accessing the CMS

  1. Navigate to /admin/ on the website
  2. Click "Login with GitHub"
  3. Authorize the application if prompted
  4. You'll be redirected to the admin dashboard

Requirements

  • ✅ GitHub account with repository access
  • ✅ Write permissions to the repository
  • ✅ Modern browser (Chrome, Firefox, Safari, Edge)

📝 Creating Posts

1

Start a New Post

Click "New Post" in the admin dashboard. You'll see the post editor with all necessary fields.

2

Fill Required Fields

  • Title: Clear, descriptive post title
  • Date: Publication date and time
  • Description: 50-160 character SEO description
  • Body: Your main content
3

Add Metadata

  • Categories: Select relevant categories (max 2)
  • Tags: Add descriptive tags (5-10 recommended)
  • Featured Image: Upload or select an image
  • Reading Time: Estimated minutes to read
4

Preview and Publish

Use the preview pane to see how your post will look. When ready, save as draft or publish immediately.

🖼️ Managing Media

Uploading Images

Method 1: Drag & Drop

  1. Drag image files into the editor
  2. Images are automatically uploaded
  3. Markdown syntax is inserted

Method 2: Upload Button

  1. Click the image upload button
  2. Select files from your computer
  3. Choose insertion options

🔄 Editorial Workflow

✏️

Draft

Create and edit your content. Drafts are saved automatically and not published.

→
👀

Review

Submit for review. Team members can comment and suggest changes.

→
✅

Approved

Content is approved and ready for publication to the live site.

Available Actions

  • Save Draft: Saves progress without publishing
  • Submit for Review: Sends to review queue
  • Request Changes: Reviewer sends back for edits
  • Approve & Publish: Publishes to live site
  • Delete: Removes draft permanently

💡 Best Practices

📖 Content Writing

  • Write compelling headlines
  • Use clear, concise language
  • Structure with headings (H2, H3)
  • Include relevant examples
  • Add call-to-action where appropriate

🔍 SEO Optimization

  • Unique meta descriptions (50-160 chars)
  • Descriptive, keyword-rich titles
  • Use headings hierarchically
  • Include internal links
  • Add alt text to all images

🏷️ Categorization

  • Use existing categories when possible
  • Maximum 2 categories per post
  • Be specific with tags
  • Use consistent tag formatting
  • 5-10 tags per post recommended

📱 Performance

  • Optimize images before upload
  • Use appropriate image formats
  • Keep file sizes reasonable
  • Test on mobile devices
  • Preview before publishing

🛠️ Troubleshooting

Login Issues

Problem: Can't log in to admin

Solution:

  1. Check you have write access to the repository
  2. Clear browser cache and cookies
  3. Try a different browser
  4. Contact admin for repository permissions
Publishing Issues

Problem: Post doesn't appear on site

Solution:

  1. Check the publish date isn't in the future
  2. Wait 2-3 minutes for build to complete
  3. Check GitHub Actions for build errors
  4. Verify the post is in "Published" status
Image Upload Issues

Problem: Images won't upload

Solution:

  1. Check file size (must be under 10MB)
  2. Use supported formats (JPG, PNG, GIF, WebP)
  3. Check internet connection
  4. Try refreshing the page
Content Not Saving

Problem: Changes aren't being saved

Solution:

  1. Check internet connection
  2. Don't navigate away while saving
  3. Try copying content and refreshing
  4. Check browser console for errors
